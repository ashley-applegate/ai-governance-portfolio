# AI-Supported Postsecondary Advising - Program Evaluation Proposal
Program Evaluation Proposal

## Overview

For this project, I developed a proposal to evaluate an AI-supported advising program designed to improve access to postsecondary education information for rural high school students.

The proposed program combines personalized AI advising with school counselor oversight, FAFSA education sessions, virtual campus tours, and information about postsecondary pathways.

My focus was on designing an evaluation that could determine whether the program improves students' knowledge and confidence while accounting for implementation challenges, student privacy, and equitable access.

## Problem Statement

Students in rural communities often have limited access to individualized postsecondary advising, information about educational pathways, and financial aid guidance.

AI-supported advising could help address these gaps, but its effectiveness would need to be evaluated before broader implementation.

This project explores how to measure the impact of such a program while maintaining appropriate safeguards for students.

## Proposed Program Design

The program would serve students in grades 9–12 at eligible rural high schools.

Key components include:

- Personalized AI advising: Helping students explore postsecondary options, admission requirements, financial aid, and individualized education plans.
- Counselor oversight: Reviewing AI-generated recommendations for accuracy and providing additional guidance.
- Supporting activities: FAFSA education, virtual campus tours, and postsecondary information sessions.

Phased implementation: Introducing the program to participating schools in stages to support evaluation and potential expansion.

## Evaluation Approach

I developed a cluster-level randomized, phased-in evaluation design.

Eligible schools would be grouped by rural classification and randomly assigned to different implementation periods. Schools awaiting implementation would serve as comparison groups until they received the program.

The proposal includes:

- Theory of change: Connecting program resources and activities to anticipated short-, medium-, and long-term outcomes.
- Causal identification: Using school-level randomization to reduce selection bias.
- Outcome measurement: Establishing baseline and follow-up assessments to measure changes in student knowledge and confidence.
- Data collection: Combining student surveys, program participation records, and relevant administrative data.
- Methodological challenges: Planning for attrition, noncompliance, spillover effects, and differences in program effectiveness across rural communities.
- Generalizability: Considering whether findings could apply to other underserved educational settings.

## Proposed Outcome Measures

### Primary Outcome

- Increased knowledge of postsecondary education options
- Measured through a standardized assessment covering:
- Postsecondary pathways
- Admission requirements
- Financial aid and FAFSA
- Identifying programs aligned with student goals
- Finding reliable information

### Secondary Outcome

Increased confidence in navigating postsecondary options

Measured through student survey responses using a structured confidence scale.

## Additional Outcomes

- FAFSA completion
- Postsecondary applications
- Postsecondary enrollment
- Program participation and implementation consistency
- Counselor workload and program costs

These are proposed measures, not results from an implemented program.

## Ethical and Implementation Considerations

The evaluation proposal addresses several challenges:

- Student privacy: Protecting information collected from minors and considering applicable FERPA, COPPA, and state requirements.
- Human oversight: Maintaining counselor involvement to identify inaccurate or inappropriate AI recommendations.
- Informed consent: Ensuring students and families understand how their information would be collected and used.
- Technology access: Accounting for differences in internet connectivity and available school resources.
- Implementation consistency: Using training, monitoring, and participation records to identify deviations from the proposed program.
- Equitable rollout: Using randomized implementation phases to allocate limited program resources transparently.

## Limitations

This was an academic evaluation proposal, not an implemented or completed program evaluation.

No schools were recruited, students were enrolled, or outcomes were measured as part of this assignment.

The proposed evaluation design, sample size, data collection methods, and implementation procedures would require further development and validation before use in a real-world study.

## What I Learned

This project strengthened my understanding of how to design an evaluation that can distinguish a program's actual impact from changes that might have occurred without it.

It also reinforced the importance of defining measurable outcomes, anticipating implementation challenges, and considering ethical requirements before introducing AI into environments involving students.
